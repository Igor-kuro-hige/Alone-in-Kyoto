# Alone in Kyoto — прогресс проекта

## О проекте

Личный блог/сайт Игоря: статьи (места для уединения, музыка, стиль, путешествия, мысли), услуга "привезти вещь из Японии" (в будущем + услуги гида). Стек: HTML/CSS сейчас, JS — следующий этап.

## Текущая структура файлов

- `index.html` — главная, сетка превью статей ("Latest")
- `place to be alone.html` — страница категории, крупные карточки с фото
- `services.html` — страница с формой "Bring something from Japan"
- `style.css` — общий файл стилей для всех страниц

## Что уже сделано (HTML/CSS)

- Семантическая вёрстка (header/nav/main/article/footer, правильная иерархия h1→h2→h3)
- Flexbox (nav), CSS Grid (сетка статей), transitions/transform (hover-эффекты)
- Reset (`* { margin/padding/box-sizing }`)
- Адаptивность: media queries (`max-width: 768px`), резиновые контейнеры
- id/class, специфичность CSS, разница margin/padding
- position: sticky (шапка), position: relative/absolute/fixed — теория разобрана
- Форма (`form`, `label for`, `input` разных типов, `textarea`, `required`)
- **Фоновое фото на весь body** — реализовано через двойной слой в `background-image`:
  ```css
  background-image:
    linear-gradient(rgba(255, 255, 255, 0.9), rgba(255, 255, 255, 0.9)),
    url("фото Киото с Unsplash");
  background-size: cover;
  background-attachment: fixed;
  ```
  Это ФИНАЛЬНЫЙ выбранный подход (проще, чем через `::before` + z-index — тот вариант разбирали, но не использовали).
- **Git настроен** — репозиторий на GitHub: `Alone-in-Kyoto` (github.com/Igor-kuro-hige). Локально: `git add` → `git commit -m "..."` → `git push`. PATH был проблемой при установке — решено, работает.
